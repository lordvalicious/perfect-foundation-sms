1. OVERVIEW

Perfect Foundation SMS is a school management system for multi-campus
institutions. It handles students, staff, finances, academics, attendance,
and communications with role-based access control.

Key Features:
- Multi-campus operations with data isolation
- Student enrollment and tracking
- Staff and teacher management
- Invoice generation and payment tracking
- Attendance and gradebook
- Internal messaging and notifications
- PDF report generation

5. DEPLOYMENT

Backend Deployment:
- Entry point: api/index.py (ASGI)
- Runtime: Python 3.12 serverless
- Database: Neon PostgreSQL (neondb_owner role)
- Build: Auto-installs requirements.txt

Frontend Deployment:
- Build: Vite static output
- API proxy: /api/* -> backend API
- SPA fallback: All routes -> index.html

7. SECURITY


- JWT authentication with 14-day sessions
- Role-based access control (Super Admin, Org Admin, Teacher, Student)
- CSRF protection with cross-origin support
- Rate limiting on login endpoints
- HTTPS enforced in production
- Passwords hashed with PBKDF2
- Multi-tenant data isolation
